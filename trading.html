🐍 Python Autonomní Exekutor (ib_insync pro Interactive Brokers TWS) 
# Autonomní odeslání Bracket příkazů do Interactive Brokers TWS
from ib_insync import IB, Stock, util

ib = IB()
# Připojení k TWS nebo IB Gateway na localhost
# 7497 = TWS Paper, 7496 = TWS Live, 4002 = Gateway Paper, 4001 = Gateway Live
ib.connect('127.0.0.1', 7497, clientId=1)

print(f"✅ Připojeno k IBKR účtu: {ib.managedAccounts()}")

# Generováno ze SuggestInvest Top 5 Conviction Basket
orders_data = [

    {
        "symbol": "RHM",
        "exchange": "SMART",
        "currency": "EUR",
        "shares": 2,
        "entry": 944.04,
        "sl": 881.36,
        "tp": 1085.65
    },

    {
        "symbol": "ALLY",
        "exchange": "SMART",
        "currency": "USD",
        "shares": 56,
        "entry": 37.76,
        "sl": 35.13,
        "tp": 53.23
    },

    {
        "symbol": "AVGO",
        "exchange": "SMART",
        "currency": "USD",
        "shares": 6,
        "entry": 345.21,
        "sl": 321.6,
        "tp": 531.85
    },

    {
        "symbol": "ORCL",
        "exchange": "SMART",
        "currency": "USD",
        "shares": 12,
        "entry": 129.34,
        "sl": 121.99,
        "tp": 237.97
    },

    {
        "symbol": "SAN",
        "exchange": "SMART",
        "currency": "EUR",
        "shares": 20,
        "entry": 71.69,
        "sl": 66.47,
        "tp": 94.06
    }

]

for item in orders_data:
    contract = Stock(item["symbol"], item["exchange"], item["currency"])
    ib.qualifyContracts(contract)
    
    # Vytvoření Parent Limit + Child SL + Child TP bracket příkazu
    bracket = ib.bracketOrder(
        action='BUY',
        quantity=item["shares"],
        limitPrice=item["entry"],
        takeProfitPrice=item["tp"],
        stopLossPrice=item["sl"]
    )
    
    print(f"🚀 Odesílám bracket příkaz pro {item['symbol']} ({item['shares']} ks @ {item['entry']})")
    for o in bracket:
        ib.placeOrder(contract, o)

ib.sleep(2)
print("✅ Všechny bracket příkazy byly úspěšně předány do TWS!")
ib.disconnect()
📖 Jak spustit exekuci v Interactive Brokers
1
Povolte API v TWS / IB Gateway
V TWS otevřete Global Configuration → API → Settings, zaškrtněte Enable ActiveX and Socket Clients a nastavte port na 7497 (Paper) nebo 7496 (Live).
2
Nastavte IP přístup
Ujistěte se, že je zaškrtnuto Allow connections from localhost only (nebo přidejte 127.0.0.1 do Trusted IPs).
3
Možnost A: Basket Trader (1-klikový import)
Klikněte na tlačítko Stáhnout TWS Basket (.csv) nahoře. V TWS otevřete nástroj Basket Trader a zvolte File → Open Basket File. Všechny nákupy a ochranné stops se ihned načtou.
4
Možnost B: Python ib_insync
Nainstalujte pip install ib_insync, zkopírujte kód vlevo a spusťte jej. Příkazy se automaticky spárují s vaším TWS.
